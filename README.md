# 大学助手 · University Assistant

一个 Codex 技能（skill）：把你个人的大学档案，变成一套**能长期跑下去**的工作区。

## 它是干什么的

装进 Codex 之后，**第一次**在某个工作区用它时，它会先带你**开通**：

问一批前置问题（怎么称呼、学校、你自己的情况、家庭、当下最要紧的事）
→ 在工作区里建三份档案文件
→ 介绍自己的能力
→ 给你几套现成的「子对话」提示词

开通之后，它就是你的**长期大学顾问**：管规划、决策、硬节点、情绪、跨文件调度。

## 核心设计：文件是唯一事实源

它**不把事实写在提示词里**，而是指向工作区里的三份文件：

| 文件 | 管什么 |
|---|---|
| `大学进度.md` | 主台账：当前状态、硬节点、优先级（同时是"有没有开通"的锚点文件） |
| `主对话交接.md` | 沟通红线、已知坑、文件地图、其他对话分工 |
| `日历提醒清单.md` | 硬节点清单 + 手动提醒方式 |

好处很实在：**你改档案，不用改技能。**

## 安装

**方式一：手动**

把 `university-assistant` 整个文件夹复制到：

```text
~/.codex/skills/university-assistant
```

Windows 上是 `C:\Users\<你>\.codex\skills\`。

**方式二：skill-installer**

在 Codex 里说：

```text
用 skill-installer，从 Har-Col/university-assistant-skill 的 university-assistant 路径装
```

仓库：<https://github.com/Har-Col/university-assistant-skill>

## 更新

技能是**一次性拷进** `~/.codex/skills/` 的，**没有自动更新**。想升级就重装一遍：

1. 先删掉（或改名备份）旧的技能目录
   - Windows：`C:\Users\<你>\.codex\skills\university-assistant`
   - Mac / Linux：`~/.codex/skills/university-assistant`
2. 再装一次：

```text
用 skill-installer 装：
repo: Har-Col/university-assistant-skill
path: university-assistant
```

安装脚本碰到同名目录会直接报 `Destination already exists`，**必须先删或改名**（没有 `--force`）。

更新只替换 skill 本体，**不会动你工作区里的档案文件**（`大学进度.md` 等）。
装完**新开一个对话**才生效。改了什么见 [CHANGELOG.md](CHANGELOG.md)。

## 用法

新开一个对话，说一句跟大学有关的事，比如 **"帮我规划一下这学期"**。

**第一次会先带你开通**（大概 5—10 分钟），之后才进入正常服务。

## 第一次会遇到什么

1. **开场白** —— 一组一组问你，问完一组等回答，不会一口气全倒出来
2. **建工作区** —— 在当前工作目录下生成三份档案文件
3. **介绍 + 子对话** —— 讲清它能做什么、子对话有什么用，再给你 2—4 套现成提示词

## 子对话

主对话的上下文是有限的，所以按领域拆子对话：

| 子对话 | 干什么 |
|---|---|
| 单科陪读 | 课后复盘、答疑、错题 |
| 刷题陪练 | 备赛、算法训练（不许直接给答案） |
| 英语备考 | 四六级 / 雅思，按题型计时练 |
| 实验室与科研 | 邮件、面试、汇报口径 |
| 比赛与活动 | 报名窗口、值不值得投 |
| 看板维护 | 可选，只有你搭了本地看板才用 |

每个都带一份**可直接复制**的提示词。

## 每日收工（可选）

一天结束说一句「收工」，它回**三段台账 + 一段人话**：

```text
今天：<1—3 件真做成的，带证据>
没做：<计划了但没动的，只陈述，不追责>
明天第一件事：<就一件>
```

前三段**不掺夸奖**，第四段**必须是一句具体的人话** —— 挂在你今天真做过的那件事上，
不是"加油""你真棒"这种放谁身上都成立的句子。

然后顺手把 `待办清单.md` 的「这几天」换成明天的版本，看板重新生成。
**它不是自动化提醒** —— 只在你开口时跑。

## 看板（可选）

**不用打开 Codex 也能扫一眼今天该干什么。** 两个东西：

1. **完整看板**（`看板.html`）—— 浏览器打开，左侧文档树 + 右侧内容，默认「今日总览」
2. **桌面小组件**（`_工具\小窗口.py`）—— 桌面角落常驻：上半张卡是日期 + 今日课程 + 明日预览 + 周期任务，
   下半张卡是待办（分组切换、可勾选、勾完划线沉底）

脚本在 `assets/kanban/` 里，**可直接复制**到你的工作区 `_工具\` 下。纯 Python 标准库 + tkinter，
不装第三方库。装的时候只改脚本顶部「配置区」的 6 处（其中只有 2 处必须改）。
详细步骤见 [references/kanban.md](university-assistant/references/kanban.md)。

## 设计原则

- **不建自动化提醒** —— 硬节点全部走你自己的手机日历
- **不编事实** —— 查不到就说查不到；报名时间、政策、分数线只给月份窗口 + 以官网为准
- **不灌鸡汤** —— 该直说就直说，不给没有依据的夸奖
- **副本会腐烂** —— 所以技能里几乎不写事实，只写"该去哪读"

## 目录结构

```text
university-assistant/
├── SKILL.md                 判定有没有开通 + 正常服务规则
├── agents/openai.yaml       UI 显示名与默认提示语
├── references/
│   ├── first-run.md         首次开通三步流程
│   ├── sub-sessions.md      子对话菜单 + 提示词
│   ├── daily-close.md       每日收工仪式（三行总结 + 替换「这几天」）
│   └── kanban.md            看板模块（可选）：从零装一套 + 怎么维护
└── assets/
    ├── templates/           档案空模板（大学进度 / 主对话交接 / 日历提醒清单 / 待办清单 / 课表）
    └── kanban/              看板的现成脚本，复制进 <工作区>\_工具\ 就能用
```

## ⚠️ 隐私提醒

这套东西会在**你本地**生成明文 Markdown 文件。
如果你把工作区同步到网盘、或者上传到公开仓库，里面的内容会跟着一起被上传 ——
**包括你自愿填写的家庭经济量级**。开通流程里会就这一条单独提醒。

技能本身**不含任何个人信息**，模板全是空的。

## 自由度

除了**保留 `LICENSE` 里那行版权**，没有别的限制。MIT 的意思是：复制、修改、合并、发布、再授权、
甚至拿去卖，都可以。

具体一点：

- 技能就是一坨明文 md + py，装在你自己的 `~/.codex/skills/university-assistant/`。
  **没有签名、没有授权校验、没有联网验证、没有"官方版"这回事。**
- `SKILL.md` 顶部的 `description` 决定 Codex **什么时候自动想起这个技能** —— 嫌它管太宽，改窄。
- `references/` 是规则、`assets/templates/` 是骨架、`assets/kanban/` 是两个纯标准库的 Python 脚本（**不联网**）。
  想删就删、想重写就重写。
- 想改名、想 fork 成自己的项目、想拉别人一起维护：随便。想署你自己的名，改 LICENSE 就是。

两点提前知道：

- **fork 出去之后，上游更新不会自动到你手里。**
- 你工作区里的**档案文件**（`大学进度.md`、`待办清单.md`…）从来不是这个项目的一部分。
  重装技能碰不到它们，改技能也伤不到它们。
