装的时候：

2. 打开 `生成看板.py`，改顶部「配置区」里的 **② 教学周基准**、**③ DOCS**（这两个必须改），
   ④⑤⑥ 按需 —— 详细说明见 skill 的 `references/kanban.md`
3. `python "<工作区>\_工具\生成看板.py"` 跑一次，确认 `看板.html` / `看板数据.json` 生成了
4. `python "<工作区>\_工具\小窗口.py"` 跑一次（**先用 `python`，别用 `pythonw`**，不然报错看不见）

## 这个程序是什么

把 `<工作区>` 下的几个 md 变成两个可看的东西：

1. **完整看板**（`看板.html`）：左侧文档树 + 右侧内容，浏览器里看全部档案，默认显示「今日总览」
2. **桌面小组件**（`小窗口.py`）：桌面角落常驻的小窗，上半区「今日课程」、下半区「待办」

目标：**不用打开 Codex 也能扫一眼今天该干什么**。

## 架构

```text
<工作区>\
├── 待办清单.md                    ← 数据源（勾选会写回这里）
├── 大学生电子档案袋\01_学业与成绩\课表.md  ← 课表数据源
├── 看板.html                      ← 生成物：完整看板
└── _工具\
    ├── 生成看板.py                ← 读 md → 产出 看板.html + 看板数据.json
    ├── 小窗口.py                  ← 桌面小组件，读 看板数据.json
    ├── 看板数据.json              ← 生成物：给小窗口用的结构化数据
    └── 小窗口设置.json            ← 窗口尺寸/位置/置顶状态
```

**数据流**：`md` →（生成看板.py）→ `看板数据.json` →（小窗口.py）→ 屏幕上

**勾选写回**：小窗口里点勾选框 → 直接改 `待办清单.md` 的 `- [ ]` / `- [x]` → 重新生成 → 重绘。
（待办的 `line` 字段是它在 md 里的行号，写回靠它定位。）


## 已知的坑（全是真踩过的，别再踩一遍）

**1. 不要用 .bat 启动（中文路径 + 编码）**
Windows 的 cmd 用 GBK 解析 .bat，但文件是 UTF-8 → 中文路径变乱码 → 命令失败、窗口一闪就没。
**现在用的是快捷方式直接指向 `pythonw.exe`**，把脚本路径当参数传——快捷方式内部是 UTF-16，没有这个问题。
桌面两个快捷方式 + 启动文件夹里的自启项，都是这么建的。

**2. tkinter 字号：正数=点，负数=像素**
写 `("微软雅黑", 10)` 是 **10 点**，Tk 会按系统 DPI 再放大一次；写 `("微软雅黑", -13)` 是 **13 像素**，Tk 不管。
**本程序一律用负像素**，并且自己做「点→像素」换算（`size * 1.3333 * k`），保证字号和手写间距同一套比例。
（踩过的后果：字号被放大 1.56 倍而间距只放大 1.25 倍 → 字挤成一团。）

**3. 高分屏发虚：必须先声明 DPI 感知**
tkinter 默认不认 DPI，Windows 会把整个窗口拉伸 → 发虚。
`__init__` 里创建 `tk.Tk()` **之前**调 `enable_dpi()`（`SetProcessDpiAwareness(2)`）。

**4. `<B1-Motion>` 不能绑在画布元素上**
绑在元素上时，鼠标一离开那个元素事件就断（右下角拖拽改大小就是这么废掉的）。
**做法**：`<Button-1>` 里把 `<B1-Motion>` / `<ButtonRelease-1>` 绑到**整个 Canvas**，松开时解绑。

**5. `overstrike`（删除线）是字体属性，不是画布元素属性**
`canvas.itemconfig(item, overstrike=True)` 会抛 `TclError: unknown option "-overstrike"`，
而且**异常会让后面的内容全部画不出来**（表现是「界面突然只剩几项」）。
**做法**：写进字体元组：`("Microsoft YaHei UI", -13, "bold", "overstrike")`。

**6. 布局顺序：底部栏要在滚动区之前 pack**
底部栏如果和内容挤在同一个容器里，内容一多就把按钮顶出窗口外。
**做法**：`top.pack(side="top")` → `bot.pack(side="bottom")` → 滚动区最后 pack 并 `expand=True`。

**7. 滚动位置用「像素」记，不要用「比例」**
`yview()[0]` 是比例。勾选后条目重排、内容高度变化，按比例恢复就会跳到别的位置。
**做法**：`canvasy(0)` 拿像素偏移，重绘后 `yview_moveto(off / 总高度)`。

**8. 数据要输出「全部待办」（含已完成）**
如果生成脚本把已完成项过滤掉，勾选后那条就从列表里消失，用户会觉得「点一下就没了」。
**做法**：`看板数据.json` 输出全部，小窗口自己按分组排序、已完成置顶。

**9. 拖动/缩放要防抖**
窗口尺寸一变就重绘全部内容会卡死。**做法**：`<Configure>` 里 `after(200, render)`，取消上一个待执行任务。

## 当前进度

**已经实现的**

- 两张圆角卡片：课表（偏蓝底）+ 待办（中性灰底），窗口四角也是圆角（靠 `-transparentcolor` 实现）
- 课表卡片：蓝色圆角时间标签 + 加粗白字课程名；「明日预览」逐行、小号灰字
- 待办卡片：按 md 里的分组显示；每条两行（加粗标题 + 缩进浅灰备注）；备注超 58 字截断
- 橙色只给「距今 ≤3 天且未完成」的任务标题用（`URGENT_DAYS = 3`）
- 勾选框 14px、按标题行高垂直居中；勾选后置顶 + 划线 + 变灰，再点可恢复
- 已完成和未完成之间有一条稍亮的分隔线
- 底栏：刷新 / 看板 / 置顶开关；右下角 ◢ 拖拽改大小
- 窗口尺寸、位置、置顶状态存在 `小窗口设置.json`，下次打开还原
- 开机自启：`启动` 文件夹里的快捷方式

**还没定 / 可以继续改的**

- 已完成项是「置顶」还是「折叠」还是「放到卡片底部」——用户还在试
- 窗口内存约 76MB（因为渲染了全部 17 条待办）。如果嫌高，可以只渲染前 N 条 + 「展开全部」
- 多显示器时窗口位置的记忆
- 字号是否跟随系统（现在是按 DPI 系数算的固定比例）

## 工作风格

- 中文，像老友，短句，Markdown 排版清楚
- **改完必须验证**：`py_compile` + 用 `python` 跑一遍看 stderr 有没有 traceback
- 改完告诉用户「桌面小组件要重启才生效」，并给出重启命令
