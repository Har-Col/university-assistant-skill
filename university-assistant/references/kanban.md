# 看板模块（可选）

只在用户提到 看板 / 待办清单 / 桌面小组件 / 小窗口，或说"不用打开 Codex 也能看"时才读这份。

## 它是什么

把工作区里的几个 Markdown，变成两个**不用打开 Codex 也能扫一眼**的东西：

1. **完整看板**（`看板.html`）—— 浏览器打开，左侧文档树 + 右侧内容，默认「今日总览」
2. **桌面小组件**（`_工具\小窗口.py`）—— 桌面角落常驻。上半张卡：日期 + 今日课程 + 明日预览 + 周期任务；
   下半张卡：待办（按组切换、可勾选、勾完划线沉底）

## 先判断用户有没有这套

看根目录下有没有 `_工具\生成看板.py`。

| 情况 | 做什么 |
|---|---|
| **有** | 已经搭好了，跳到「日常维护」 |
| **没有** | 问一句他想不想要，**别硬推**。想要就走「从零装一套」 |

## 从零装一套

### 第 1 步 · 补两个数据源文件

技能默认只建 3 份档案（`大学进度.md` / `主对话交接.md` / `日历提醒清单.md`）。
看板还要读下面两个，从模板复制过去，**带用户过一遍写在文件顶部的格式说明**：

| 从哪来 | 放到哪 |
|---|---|
| `assets/templates/待办清单.md` | `<工作区>\待办清单.md` |
| `assets/templates/课表.md` | `<工作区>\课表.md` |

课表建议用户直接从教务系统复制课程信息，你帮他理成三列表格（`| 课程 | 周X N-M 节 | 周次 |`）。

### 第 2 步 · 放脚本

把 `assets\kanban\` 里的三个文件复制进 `<工作区>\_工具\`：

```text
<工作区>\
└── _工具\
    ├── 生成看板.py                  ← 读 md → 产出 看板.html + 看板数据.json
    ├── 小窗口.py                    ← 桌面小组件，读 看板数据.json
    └── 看板小程序_子会话Prompt.md    ← 给专职子对话用（第 5 步）
```

**不用装任何第三方库**，Python 标准库 + tkinter 就够。

### 第 3 步 · 改配置（`生成看板.py` 顶部的「配置区」，一共 6 块）

| # | 改不改 | 是什么 |
|---|---|---|
| ① 工作区根目录 | **不用改** | 默认取脚本所在目录的上一级，搬走也不用改 |
| ② 教学周基准 | **必须改** | 挑一个确定的「某周周一」+ 那天是第几周。填错的话"今天是第几周 / 今天上什么课"全错 |
| ③ `DOCS` | **要改** | 收录哪些文档。改成他工作区里**实际存在**的文件；偷懒就写 `[]`，脚本会自动收录所有 `.md` |
| ④ `RECURRING` | 可选 | 周期任务（"每周 3 次"这类）。没有就写 `{}` |
| ⑤ `ROS_DOC` | 可选 | 按周推进的长任务日程。指不到会自动跳过，不报错 |
| ⑥ `BUILTIN_EXCEPTIONS` | 一般不改 | 节假日兜底。平时往 `课表.md` 的「## 例外日期」表里加行就行，md 优先 |

### 第 4 步 · 跑起来 + 验证

```bat
python "<工作区>\_工具\生成看板.py"    :: 生成 看板.html + 看板数据.json
python "<工作区>\_工具\小窗口.py"      :: 先别用 pythonw，这样报错能看见
```

`看板数据.json` 是有用的中间产物，**别手删**：周期任务的「本周第几次」就存在里面。

然后建开机自启：在「启动」文件夹放一个指向 `pythonw.exe` 的快捷方式，参数写脚本路径。
⚠️ **不要用 .bat 启动** —— cmd 用 GBK 解析 .bat，中文路径会乱码，窗口一闪就没（真踩过）。

### 第 5 步 · 开一个专职子对话

把 `_工具\看板小程序_子会话Prompt.md` 的提示词正文整段复制，让用户新开一个对话粘进去。
那份提示词里有 **9 条 tkinter 硬坑**（DPI 发虚、字号点数 vs 像素、`overstrike` 只能写进字体、
拖拽事件要绑整个 Canvas……）和参考实现已经做到什么程度 —— **照着做，出来的东西基本是同一个**。

## 数据源的格式要求（脚本认死的）

格式不对**不会报错**，只是那块不出现在看板上。

**待办清单.md**

```md
## 分组名                          ← 二级标题 = 分组
- [ ] **标题** —— 备注             ← **标题** 必须加粗；备注画成第二行小字
```

**课表.md**

```md
| 课程 | 时段 | 周次 |
|---|---|---|
| 高等数学 | 周一 1-2 节 | 1-18 周 |     ← 三列。周次支持 4-5,7,9-10
```

例外日期读 `## 例外日期` 下的表：`| 2026-10-01 | 停课 | 国庆假期 |`

**长任务日程（可选，`ROS_DOC` 指向的那份）**

```md
## 8 周表
| **1** | 10/08（四）—10/11（日） | 4 | 001—015 | 17 | 2h10m | ~32 分 |

## 逐日安排
### 2026-10-10（周六）· 目标 31 分钟      ← 标题里要带「目标 N 分钟」
- 032 ROS架构之文件系统（11.1）           ← 一集一行，看板展开成可逐项勾选的小条目
```

## 日常维护（已经装好的情况）

- ✅ **保证数据源对得上**：滚动待办要和主台账的结论一致
- ❌ **不要改 `_工具\` 下的脚本**（`生成看板.py`、`小窗口.py`）——那是**「看板小程序维护」子对话**的辖区
- ❌ 不要手改 `看板.html` / `看板数据.json`——都是生成物，重跑脚本就覆盖了
- 改了 `待办清单.md` / `课表.md` 之后，**重跑一次 `生成看板.py` 才生效**
