# 每日收工（可选仪式）

**触发**：用户说「收工」「今天到这」「睡了」「今日总结」「今天咋样」这类话。
**它不是自动化**：只在用户开口时跑。任何情况下都不要为它建 automation / heartbeat。

## 为什么要这个

用户要的是**一天结束时看见自己做了什么**。
事实被摆出来是地基——但地基不是房子。用户原话：**「还是需要鸡汤环节的，温度，人文关怀。」**

所以这个仪式是**三段信息 + 一段人话**，两条都不许省：

- 前三段**不许注水**：只写事实，不把没做的事说成好事
- 第四段**不许偷懒**：必须真的看着"他今天这个人"说一句话

只做前三段 = 打卡机；只做第四段 = 说空话。

## 四步，一次做完

### 1. 对表（很快）

- 今天几号、星期几、第几教学周
- 读 `待办清单.md` 的「这几天」一节 —— 这是唯一要改的地方
- 扫一眼各子对话台账里**日期是今天**的条目（**只读**，别人的台账别动）

### 2. 回三段，不多不少（给脑子的）

```text
今天：<1—3 件真做成的，带证据：勾掉的待办 / 台账里今天的记录>
没做：<今天计划了但没动的。只陈述，不追责、不劝、不找补>
明天第一件事：<就一件，具体到"看哪几集 / 写哪一页 / 发给谁">
```

- **这三段里不掺夸奖**，一句都别掺 —— 夸奖留给第 4 步。
- **「没做」那行不许写成鸡汤**。就写没做。
- 一整天确实什么都没做：照实写一行，不找补。

### 3. 说一段人话（给心的，别跳）

前三段是台账，这一段才是"有人陪着你过完这一天"。**一到三句，不要更多。**

两条规矩：

1. **必须挂在他今天真做过的事上**，不能是放之四海皆准的句子。
   判断方法：把主语从"他做了什么"换成"他很棒"，如果句子还成立，那就是废话。
   - ✅「那几个报错没人能替你想，你就是一行一行试出来的」
   - ❌「你很努力，继续加油」
2. **关心要给具体的**：他的睡眠、他的身体、他扛着的那件事、他主动砍掉的那件
   （**砍掉也是判断力，不是偷懒**）。别在这里给建议、别布置任务——上面已经说过了。

**不许出现**（说了等于没说）：

> 加油 / 你真棒 / 相信你可以 / 未来可期 / 一切都会好的 / 后浪 / 星辰大海

「辛苦了」单独说也是空的；挂在具体那件事后面，才是真的。

**可以出现**：

> 具体的那一下有多难 · 他哪一次没有放弃 · 他做的哪个判断其实是对的 · 他该睡了

### 4. 落盘（别只在聊天里说）

- `待办清单.md` 的「这几天」**整段替换**成明天的版本（这一节设计上就是每日替换）
- 今天做完的条目标 `[x]`，或挪到「本月已完成」
- 有看板就重跑 `_工具\生成看板.py`
- 可选：往「个人成长与复盘」类目录下追加一行月度日志（目录名以工作区实际为准）——
  例如 `06_个人成长与复盘/2026-10 · 一行日记.md`，格式 `- 10/09：<一句话>`

## 红线

- 不建 automation。
- 只改「这几天」和日志；别的台账归各自的对话。
- 用户说「今天就这样」→ 就收工，别再问"要不要多做一点"。
- 没东西可写就别硬凑。宁短勿长。
- **别把「有温度」做成「演」**：第四段一旦开始抒情、上排比、堆形容词，就已经不是在看他了。
  宁可短一点、钝一点，也要具体。
